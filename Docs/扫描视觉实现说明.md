# Q 切换式球形扫描视觉

当前工程 UE 5.5，测试关卡 Levels_Demo，角色 CBP_SandboxCharacter_Child。

## 当前效果

- 第一次按 Q 开启扫描，以玩家当前位置为中心快速向外扩散，经过的区域从近处浅银蓝向外缘灰蓝连续渐变，保留光照、投影和接触阴影。
- 扩散和收回期间，中心每帧跟随玩家。移动时无需重新按 Q，扩散计时不会重置。
- 扫描区内所有可见的不透明/蒙版模型显示深度＋世界法线的拉普拉斯结构线，无需 Scannable 标签，也无需开启 Custom Depth。
- 带 Scannable 标签的目标额外获得青色高亮与轮廓。遮挡时显示半透明青蓝剪影和轮廓；按目标实际表面距离判断波前到达时间。
- 从4.5米开始，颜色、普通结构线、目标高亮和穿墙轮廓逐渐淡出，10米归零，避免明显的圆形边界。
- 玩家网格保持原画面，排除浅灰、结构线和目标描边；目标描边采样也避开玩家边界。
- 再次按 Q 关闭扫描 从当前半径反向收回，外侧先恢复，结构线和高亮随同一空间渐变消退。
- 收回期间再次按 Q 会取消旧清理计时器、重新外扩。角色 EndPlay 立即清理。

这里的拉普拉斯效果显示模型轮廓和表面结构转折，不显示真实三角面拓扑。普通后处理深度/法线不能还原全部三角形，也不能完整读取透明材质的表面。

## 角色参数

在 CBP_SandboxCharacter_Child 类默认值调整：

| 参数 | 当前值 | 含义 |
| --- | --- | --- |
| ScanRadius | 1000 cm | 最大扫描范围与目标查询半径 |
| ScanWaveSpeed | 2200 cm/s | 外扩与收回速度；约为上一版的3.4倍 |
| ScanWaveWidth | 180 cm | 空间渐变过渡宽度 |
| ScanInterval | 0.1 s | 候选目标查询间隔；视觉跟随仍每帧更新 |
| ScanTargetTag | Scannable | 可交互目标 Actor 标签 |

速度越大越快。当前10米范围外扩至过渡带末端约0.54秒；关闭时按已经扩散的实际半径收回。

## 材质参数

主材质 /Game/RefractionRift/02_Materials/Master/M_PP_ScanVision。
参数实例 /Game/RefractionRift/02_Materials/Instances/MI_PP_ScanVision。

| 参数 | 当前值 | 调整方式 |
| --- | --- | --- |
| EnvironmentBrightness | 0.5 | 渐变色整体亮度，0.5对应原始色板亮度 |
| EnvironmentDetail | 0.65 | 原场景明暗细节的保留强度 |
| GeometryLineWidth | 1.0 px | 普通模型结构线宽度 |
| GeometryDepthThreshold | 0.004 | 深度边缘阈值，越小越敏感 |
| GeometryNormalThreshold | 0.18 | 法线转折阈值，越小线条越多 |
| GeometryLineOpacity | 0.38 | 结构线强度 |
| GeometryLineColor | (0.13, 0.24, 0.30) | 普通结构线颜色，默认柔和青灰 |
| OutlineWidth | 2.5 px | Scannable 目标的青色外轮廓宽度 |

径向色板从 ScanInnerColor 浅银蓝 (0.68,0.76,0.81) 过渡到 ScanOuterColor 灰蓝 (0.25,0.32,0.38)，GradientPower=0.85 控制曲线。
颜色再乘以原场景亮度形成的明暗细节，并通过扫描波与距离淡出混合回原画面。
DistanceFadeStart=0.45 表示从最大半径的45%开始淡出；越小越早变淡。环境、结构线和目标效果共同使用该范围。
结构线使用中心与上下左右四点的深度和法线差分：深度差按距离归一化，法线差补充表面转折，再按阈值平滑输出。

## 蓝图执行链

1. IA_Scan Started → RR_ToggleScan：未开启或正在收回时开启，否则关闭；Completed/Canceled 无连接，松开不切换。
2. RR_StartScan：激活，初始化动态材质和计时，开启后处理，查询候选，启动刷新定时器。
3. RR_PrepareScanWave：首次创建 ScanVisionMID 并加入带 RR_ScanVision 标签的后处理体积；初始化当前位置、速度、宽度、最大半径和反向状态。
4. Event Tick：先调用父类 Tick；扫描或收回期间，只刷新 ScanOrigin 与 MID 的 PlayerPosition，不重复做重叠查询。
5. RR_UpdateScan：每 ScanInterval 秒在跟随玩家的中心查询 Scannable 候选，写入 Stencil 1。
6. RR_StopScan：记录关闭时间，材质切换到反向半径；保留视觉与目标查询直到收回结束。
7. RR_FinishScanReturn：关状态和后处理，停止定时器，清理目标并恢复玩家标记。
8. RR_UpdatePlayerStencil：玩家 MeshComponent 扫描期间写入 Stencil 2，结束时关闭并归零。

普通场景结构线直接使用场景深度/法线，与目标重叠查询独立。蓝图已补充中文分组及关键节点备注。

## 场景与模板值

PP_ScanVision 为无限范围体积，Actor 标签 RR_ScanVision，默认 BlendWeight=0。首次扫描装入动态材质，后续复用。
原 MI_Check_Outline 不单独叠加，目标轮廓已合并到主扫描材质。
项目启用 r.CustomDepth=3。Stencil 1 表示目标，2 表示玩家。
当前原型约定目标和玩家组件原始 Custom Depth 关闭、Stencil 为0，清理后恢复到此状态。

在 MI_PP_ScanVision 调整：

| 参数 | 当前值 | 含义 |
| --- | --- | --- |
| XRayEnabled | 1 | 是否启用遮挡目标透视 |
| XRayOpacity | 0.30 | 墙后目标剪影的填充强度 |
| XRayOutlineOpacity | 0.85 | 墙后目标轮廓强度 |

## Q 输入方式

第一次按下Q开启，松开后持续扫描；第二次按下Q关闭并播放原收回动画。收回期间再按Q立即重新开启，旧清理计时器会取消。状态使用 bScanActive 且非 bScanReturning 判断，不依赖 FlipFlop。蓝图输入分组及相关备注已同步更新。

## 描边延迟

MI_PP_ScanVision 新增 OutlineDelay=1.0，单位秒。场景结构线、目标轮廓以及穿墙轮廓使用延后1秒的扫描波，随后按原过渡宽度淡入。领域颜色、目标亮面和墙后填充仍使用原扫描时序。
关闭时冻结延迟波的外扩进度，并和原收回半径取较小值，防止等待中的描边在关闭期间突然出现；再次按Q开启会重置计时。
