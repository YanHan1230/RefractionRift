# 结构修复：扫描发现断桥 → 靠近终端 → E 重建 → 通行

当前版本是可试玩的功能原型，使用基础几何体验证玩法与材质表现。与已有 Q 扫描联动，保留原来的扫描开关、扩散、回收和描边延迟。

## 试玩方法

1. 打开现有关卡 `Levels_Demo`。
2. 在世界大纲搜索 `BP_RepairBridge_Demo`；编辑模式选中它，按 F 可以定位。Actor 位于 X=1000、Y=-700、Z=0。
3. 运行游戏，找到带有 `Q > E` 标识和青色终端的高台。通过入口的两级台阶登上平台。
4. 按 Q 开启扫描。扫描波到达桥入口后，桥面显示青色全息线框，并提示发现可修复结构。
5. 靠近青色终端，按 E 开始修复。默认交互距离为 280 厘米。
6. 桥面从入口向对岸推进显现，青色能量边扫过后留下实体桥面。约 2.4 秒完成，完成后即可通行。

修复前桥面没有碰撞，不能踩着全息预览过去。修复过程中重复按 E 不会重置进度；离开终端或关闭扫描不会中断重建。已经发现的桥在本次游戏会话中保持可修复，结束运行后重置。

## 蓝图阅读顺序

打开 `BP_RepairBridge` 的事件图表，按中文注释框的 01～08 阅读：

1. **初始化**：创建共享动态材质，向材质传入桥的位置、前向和右向。实体桥面初始没有碰撞。
2. **每帧刷新**：按“发现 → 交互 → 重建”的顺序更新。
3. **扫描发现**：读取当前角色的扫描状态、范围、波速和开始时间。扫描波到达桥入口才显示全息预览，不是在按下 Q 时立即发现。
4. **靠近交互**：计算玩家到终端的世界空间距离，显示中文提示，读取 E 按下的那一帧。
5. **请求校验**：同时满足“已发现、在范围内、未完成、未修复中”才启动重建。
6. **修复动画**：每帧把 `DeltaSeconds / RepairDuration` 累加到 `RepairProgress`，限制在 0～1，传给材质。
7. **完成通行**：进度到 1 后切换桥面碰撞配置为 `BlockAll`，隐藏全息预览。
8. **原型重置**：`RR_ResetRepair` 恢复未发现、未修复、无碰撞状态；供调试或未来关卡重置调用，没有绑定玩家按键。

## 材质的关键原理

`RepairProgress` 从 0 增加到 1；乘以桥长得到“目前修到多远”。材质用世界坐标减去桥入口位置，再与桥的前向做点积，得到每个像素沿桥方向的距离。比较两者：修复前沿后方显示，前方裁掉。

六块桥面共享同一个动态材质，所以前沿连续地越过整座桥。前沿附近发出较亮的青色光，经过后变为较暗的蓝灰色实体，保留细网格。全息预览是独立的无碰撞网格，修复完成后隐藏。

## 主要参数

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| RepairDuration | 2.4 | 修复时长，单位秒；数值越小，推进越快 |
| InteractionRange | 280 | 玩家到终端的交互距离，单位厘米 |
| BridgeLength | 720 | 材质修复前沿推进的长度，单位厘米 |
| RepairProgress | 0～1 | 运行时进度，由蓝图更新 |

此原型桥长 720 厘米、宽约 260 厘米，由六块桥面组成。若修改实体桥长，也要同步调整组件位置、对岸平台位置和 `BridgeLength`；只改参数不会自动生成新几何体。整体 Actor 移动或旋转后，材质方向仍跟随桥；当前按整体缩放为 1 设计。

## 验证结果与当前范围

已在编辑器运行状态验证：未发现或距离过远时请求被拒绝；扫描波到达后发现；修复进度递增；重复请求不重置；完成后隐藏预览并开启实体碰撞；重置后恢复缺桥。实际下落测试中，修复前角色落到地面，修复后落在桥面。

最初验证通过调用与 E 共用的 `RR_RequestRepair` 事件触发，没有覆盖按键读取。后续发现 E 按键参数格式错误：UE 的 FKey 引脚必须填写 `E`，原来的 `(KeyName="E")` 会被解析为无效按键，导致提示出现但按键没有反应。现已修正此引脚，并在该节点旁增加中文说明。

同时补接了“获取扫描开始时间”节点的执行线，避免编译器将未执行的读取结果替换为默认值，确保发现判断按扫描波实际到达时间计算。

修复后已通过 UE PlayerController 的输入通道注入 Q/E 按下与松开事件，连续两轮验证“Q 扫描发现 → E 开始修复 → 进度完成 → 开启碰撞”，并验证发现前按 E 被拒绝、重建中再次按 E 不重置进度。此次验证经过了按键读取节点，没有直接调用修复事件；未模拟 Windows 物理键盘。临时测试节点已清除。

当前使用屏幕调试文字作为中文交互提示，没有制作正式 HUD；未加入资源消耗、存档、联机或导航网格更新。玩法与材质在普通蓝图中执行，游戏运行时不依赖 MCP。
