# 材质中文助手 1.1 · UE 5.5

适合从美术转向技术美术、希望用中文理解材质节点的学习者。

## 安装

本包已包含 Windows 64 位编辑器插件，无需安装 Visual Studio。使用 Epic 安装版 UE **5.5.4** 编译和验证；其他 UE 5.5 补丁版本或自编译引擎，可能需要重新编译。

1. 保存并关闭要安装插件的 UE 工程。
2. 解压安装包。
3. 打开 `MaterialChineseHelper` 文件夹，双击 `安装插件.cmd`。
4. 在文件选择窗口中，选择你的工程 `.uproject` 文件。
5. 重新打开工程。如果没有自动启用，在“编辑 / Edit → 插件 / Plugins”搜索 **Material Chinese Helper** 并启用，按提示重启。

安装器支持初次安装和升级。已有旧版时，会先备份到工程 `Saved/MaterialChineseHelperBackups`，再复制新版。你的旧词表也会保存在备份中。同名文件夹若不是本插件，安装器会停止。也可以手动复制整个 `MaterialChineseHelper` 文件夹到工程的 `Plugins` 文件夹。

正确的目录结构：

```text
你的工程/
├─ 你的工程.uproject
└─ Plugins/
   └─ MaterialChineseHelper/
      ├─ MaterialChineseHelper.uplugin
      ├─ Binaries/Win64/UnrealEditor-MaterialChineseHelper.dll
      ├─ Resources/NodeDictionary.json
      └─ Source/...
```

请避免多套一层 `MaterialChineseHelper/MaterialChineseHelper`。

## 使用

- 打开材质或材质函数编辑器，常用节点会在约一秒内显示中文与英文。
- 鼠标悬停在支持的节点上，查看中文用途说明。
- 常用接口显示中文与英文，悬停查看接口解释。例如 Fresnel 的 ExponentIn 会显示为“指数 (ExponentIn)”。
- 在主编辑器顶部打开 **工具 / Tools → 材质中文助手**，可开启或关闭中文、英文对照和接口翻译。
- **在材质编辑器画布右键弹出的原生搜索框里，直接输入“菲涅耳”“混合”“法线”“地形”等中文，选择结果即可添加原生节点。英文搜索同样保留。**
- 原生菜单首次打开后，插件通常在约 0.1 秒后更新名称和索引。已经输入的中文也会保留并重新匹配。
- 助手面板也支持中文或英文搜索，并提供中文说明和英文名称复制功能。
- 如果暂时没变化，可重新打开材质编辑器，再检查插件是否已启用。

## 覆盖范围

本版包含 **299 个原生材质节点条目、392 个内置材质函数名称、317 个接口名称及别名条目**。覆盖清单按本机 UE 5.5.4 的实际类和原生菜单导出，包含地形、运行时虚拟纹理、体积、后处理、Substrate 等进阶节点。

299 是当前验证环境中加载的非抽象、非弃用材质表达式类数量；其中原生右键菜单实际出现 262 种节点类，其他类受引擎内部用途、项目功能或渲染设置限制。汉化不会把原本不可用的节点强行加入菜单。

392 个函数名称包含常用函数的直接译名，以及部分进阶函数的术语组合译名；组合翻译的条目在说明中已标注，并保留英文供核对。这不是对所有函数算法的完整中文教程。部分进阶节点和接口仅提供基本说明。

典型显示效果：

| 原名称 | 插件显示 |
|---|---|
| Fresnel | 菲涅耳·视角遮罩 (Fresnel) |
| Lerp | 线性插值·混合 (Lerp) |
| Multiply | 相乘 (Multiply) |
| PixelNormalWS | 像素世界法线 (PixelNormalWS) |
| ExponentIn | 指数 (ExponentIn) |
| BaseReflectFractionIn | 正面基础值 (BaseReflectFractionIn) |

节点有数字、资源名或动态标题时，会保留这些信息，例如“标量常量 · 0.18”。参数可编辑的标题保留你定义的名称，类型说明与悬停提示补充中文。

## 本版边界

- 原生右键菜单、节点面板中的名称和搜索索引会一起更新；节点创建仍使用 UE 原本的动作，连线筛选规则保持原样。
- 覆盖本机 UE 5.5.4 验证清单中的原生节点和对外公开的内置材质函数名称。第三方插件节点、全部细节面板属性、函数内部自定义接口和自定义资源名称不保证完整汉化。
- 未收录的名称保留原样。自定义参数标识符、函数标识符、HLSL 代码、节点连线和材质数值不会被翻译写入。
- 这是纯编辑器显示插件，不会向材质添加运行时依赖，不影响材质计算与游戏打包。
- 开启中英对照后，部分节点会变宽。学习时建议保留英文，熟悉后可在助手面板中关闭。
- 如果其他插件也修改同一批节点的 Slate 文本，显示效果可能相互覆盖。

## 恢复与卸载

临时恢复：在助手面板取消“启用节点中文显示”，已有节点恢复原名称。

卸载：关闭 UE 后，把工程 `Plugins/MaterialChineseHelper` 文件夹移出工程。若工程文件中曾手动启用此插件，提示缺少插件时选择禁用即可。材质资产不需要转换回来。

## 自定义词表

中文与说明位于 `Resources/NodeDictionary.json`，采用 UTF-8 编码。关闭编辑器后修改，重启加载。每个节点通过稳定的类名识别，避免依赖节点显示文字。

## 验证情况

已使用本机 Epic 安装版 UE 5.5.4 / Windows 64 位编译，并运行插件自身的编辑器自动化检查，覆盖：

- 词表中的原生节点类可被引擎识别。
- UE 原生材质节点控件的中文标题与接口显示。
- 重复扫描、节点重建、关闭接口翻译、中英切换与恢复。
- UE 原生搜索菜单中的中文匹配、英文匹配、无匹配情况、原始创建动作保留，以及恢复原名称与索引。
- 当前验证环境实际加载的 299 种表达式类、原生菜单 262 种节点类、392 个内置函数名称均可在词表中找到。
- 参数可编辑名称保留，原始节点名称、接口标识符、数值和脏标记不被翻译修改。

5 项自动化检查在独立临时工程运行，使用 NullRHI 检查原生 Slate 控件、搜索结果和数据，没有修改你的现有工程。尚未在你的学习工程中进行完整交互验收。

## 源码与重新编译

包内附 C++ 源码。更换引擎版本或使用自编译引擎时，应先退出 UE，再使用对应引擎的 `Engine/Build/BatchFiles/RunUAT.bat` 的 `BuildPlugin` 命令编译。本版模块只在编辑器中加载。

详细学习内容见同目录 `节点学习词典.md`。
