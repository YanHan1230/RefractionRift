# 1.1 更新

- 原生材质节点右键菜单支持中文名称和中文搜索，英文搜索保留。
- 不清空用户已经输入的中文查询；更新索引后立即重新匹配。
- 原生节点词表由 123 项扩展到 299 项，覆盖本机 UE 5.5.4 实际加载的全部非抽象、非弃用材质表达式类。
- 添加 392 个引擎内置材质函数名称，部分进阶名称采用术语组合翻译并明确标注。
- 接口名称及别名扩展到 317 项，保留原有重点节点的专用解释。
- 支持旧版升级，先备份旧插件和词表，再复制新版。

安装前先保存并关闭工程。解压后双击 `安装插件.cmd`，选择原工程即可升级。

本次验证范围是 Epic 安装版 UE 5.5.4 / Windows 64 位。第三方节点、全部属性面板和用户自定义名称不在完整覆盖承诺内。
