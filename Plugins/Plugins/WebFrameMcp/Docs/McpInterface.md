# MCP 核心模块

## 简要说明
核心模块负责编辑器内 MCP WebSocket 服务、连接状态、调用日志、操作记录、模块开关、路径权限以及通用资产操作。其他功能模块都会复用这里提供的日志和权限能力。

## MCP 接口
- `mcp.ping`：检测 MCP 服务是否可用。
- `mcp.status`：返回服务状态、端口、已注册接口数量、模块启用状态和路径权限状态。
- `mcp.record_operation`：把外部 MCP 操作写入插件的操作记录。
- `blueprint.record_change`：兼容旧调用的别名，效果等同于 `mcp.record_operation`。
- `asset.rename`：使用 UE 资产工具重命名资产，并尽量保持引用关系正确。

## 常用参数说明
- `assetPath`：UE 资产路径，通常是 `/Game/...` 或 `/All/Game/...`。
- `oldPath` / `newPath`：重命名前后的资产路径。
- `summary`：操作记录里展示的简短说明。
- `details`：操作记录里可展开查看的明细列表。

## 注意事项
- 模块开关只控制对应 MCP 接口是否响应，不影响文档和配置文件加载。
- 路径权限按模块独立配置；某个模块被限制后，只影响该模块的访问和修改。
- 调用日志按小时写入文件，只有发生外部 MCP 调用时才会生成日志文件。
